# One-minute demo script

**Setup before recording.** The bot is deployed and the webhook is verified (`npm run telegram:set-webhook`). Telegram is open on Meera's private channel. The Supabase Table Editor is open in a second window on `notes`. Clear any old test drafts from view by scrolling the channel to the bottom.

| Time      | Do                                                                                                                                                                                                                                                                          | Say                                                                                                                                                                                                   |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00–0:08 | Show the empty channel.                                                                                                                                                                                                                                                     | "This is Meera's private Telegram channel. She drops raw notes here. She has sixty unused ones and hasn't posted in eleven weeks."                                                                    |
| 0:08–0:15 | Post the weak note: `Remind me to reorder cartons tomorrow.`                                                                                                                                                                                                                | "First, a note that shouldn't become a post."                                                                                                                                                         |
| 0:15–0:22 | Within a few seconds the bot replies **No draft created · score 1/10** with a one-line reason.                                                                                                                                                                              | "Gemini scored it, it fell below six, and the pipeline stopped. No drafting call was made. She sees why."                                                                                             |
| 0:22–0:30 | Paste the strong note (batch fourteen, the supplier's silent preservative change, pH down about 0.4 units, texture changed, compare every CoA against a baseline).                                                                                                          | "Now a real observation from her manufacturing records."                                                                                                                                              |
| 0:30–0:42 | The bot replies with **Draft XXXXXX · pending your review**, the score and reason, the draft text, and, if a relevant story was found, the `NEWS SOURCE / FROM / LINK / CHECK BEFORE PUBLISHING` block. Two buttons: **Approve** and **Reject**. Scroll through it briefly. | "It scored it, checked Google News for a current angle, and drafted in her voice from a versioned voice profile. Evidence first, no emojis, no hashtags. Any news source is shown for her to verify." |
| 0:42–0:50 | Tap **Approve**. A toast confirms, the buttons disappear, and the bot posts _Draft XXXXXX approved. It has not been published._ Tap the same button area again, or type `APPROVE XXXXXX`, to show the bot answers _already approved_.                                       | "She's the gate. One tap approves it. Repeated taps change nothing."                                                                                                                                  |
| 0:50–1:00 | Switch to Supabase: show the `notes` row (score, status `drafted`), the `drafts` row (status `approved`, voice skill version), and `draft_reviews` (who, when, update ID).                                                                                                  | "Every note, draft, and decision is stored, including the rejected one. Nothing is ever posted to LinkedIn automatically. She copies the approved draft herself."                                     |

**If something goes wrong on camera.** If no reply arrives within about 30 seconds, run `npm run telegram:set-webhook` and check `last_error_message`, then open `/api/health`. The note is already saved, so resending it is safe; the duplicate update is ignored.
